What is enforced

  • Bound to localhost — not advertised on the LAN
  • Session cookies: HttpOnly, SameSite=Strict, 8-hour expiry
  • CSRF tokens on every state-changing form
  • Login throttling after repeated failures
  • Passwords stored with PBKDF2-HMAC-SHA256 (210k rounds)
  • Path confinement so uploads cannot escape the repository
  • Member IDs masked in the UI
  • OpenAPI/docs endpoints disabled
